## What Kiro is

Kiro is AWS's AI coding agent. You state your intent and its agents plan, build, review and verify the work.
One agent harness powers every surface (IDE, VS Code extension, CLI, Web, Mobile), and project configuration
lives in a shared `.kiro/` folder. Kiro Crew is the open-source app for persistent background agents ("bots")
with memory, schedules and triggers.

Features judges look for:

- **Specs**: requirements → design → tasks before code; Bugfix Specs; property-based tests (PBT).
- **Steering**: persistent project rules and conventions.
- **Hooks**: automations triggered by file changes, tool use or task completion.
- **MCP and Powers**: external tools, and packaged tools with built-in expertise.
- **Custom agents, sub-agents, skills**.
- **Kiro Crew**: bots, conductor mode, scheduled and event-driven work.

## Judging

Stage 1 is pass/fail: does it fit the theme and use Kiro enough? Stage 2 scores five criteria, 20% each:

1. **Potential Impact**: a real problem for a real audience; would someone use it?
2. **Technological Implementation**: depth and variety of Kiro use; a thoughtful AI-development strategy.
3. **Design**: a complete, polished product, not a proof of concept.
4. **Innovation / Idea**: novelty; unusual technologies or public datasets.
5. **Presentation**: the video shows it working end to end with a clear, memorable pitch.
