# Last Will.exe

A digital-legacy dead man's switch for the [Kiroween 2026](https://kiroween.devpost.com/) hackathon
(Frankenstein category). You check in regularly. If you stop responding, encrypted instructions and letters
are released to the people you chose using secret sharing, and an AI "executor" guides your family through
closing your accounts.

**Status:** research done, build not started. Submission deadline: Dec 4, 2026, 2:00 PM PT.
